# SpokenDex-data

Data voor de SpokenDex-app: talen en varianten per set, Engelse namen voor Aziatische sets,
kaarten die TCGdex mist en koppelingen tussen westerse en Aziatische prints.

Wordt gemaakt met `Tools/publish-data.py` in de app-repository; niet met de hand bewerken.
De app leest `manifest.json` (huidige versie: 202610101112) via GitHub Pages.
